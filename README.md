# transport

Plataforma tipo Uber para transporte de carga en México: conecta empresas que necesitan mover mercancía con empresas transportistas.

- **Perfiles:** Cliente, Transportista, Operador y Admin (una sola app con vistas por perfil)
- **Plataformas:** iOS y Android, español primero
- **Ruta piloto:** Monterrey → Guadalajara

Ver [docs/kickoff-meeting-notes.md](docs/kickoff-meeting-notes.md) para el contexto completo.
